# Data

## AWS price snapshot

| | |
|---|---|
| File | `internal/pricedata/aws-prices.json` (+ `.sha256`) |
| Source | AWS Price List Bulk API offer files, `https://pricing.us-east-1.amazonaws.com/offers/v1.0/aws/<Service>/current/<region>/index.json`, for AmazonEC2, AmazonRDS, AmazonS3, AWSLambda and AWSELB in us-east-1 and eu-west-1 |
| Retrieved | 2026-10-25 (offer versions and publication dates are recorded in the file and shown by `planprice snapshot info`) |
| Content | 7,587 on-demand prices, reduced to identifying attributes, unit and price tiers; about 1.8 MB |
| Produced by | `make snapshot` (`cmd/pricegen fetch` + `build`), see [docs/PRICE_SNAPSHOT.md](docs/PRICE_SNAPSHOT.md) |
| Terms | The offer files are published without authentication for programmatic use. Each carries AWS's disclaimer: "This pricing list is for informational purposes only. All prices are subject to the additional terms included in the pricing pages on http://aws.amazon.com." No separate data licence is stated. The repository's MIT licence covers the code, not AWS's price data. |

Prices are list prices for on-demand usage at the snapshot date. They are not
a quote, exclude taxes, discounts, Savings Plans, Reserved Instances, free
tiers and data transfer, and will drift from current AWS prices over time.

## Terraform plans

| | |
|---|---|
| Files | `testdata/plans/base.json`, `head.json`, `multi-region.json` |
| Source | Generated by this repository from `examples/` with `scripts/gen-plans.sh` (Terraform 1.15.8, hashicorp/aws 6.68.0), `terraform plan` + `terraform show -json` |
| Nature | Real Terraform output for **fictional** infrastructure. The provider uses fake static credentials and skips every account check, so no AWS account was involved; AMI ids, subnet ids, bucket names and the VPC id are placeholders. |
| Licence | MIT (part of this repository) |

`internal/tfplan/testdata/synthetic-v5.json` is a hand-written plan in the
same format, used to test update/delete/replace actions, module-scoped
providers and variable-based regions (create-only mock plans cannot contain
those). `internal/pricegen/testdata/AmazonEC2-eu-west-1.json` is a hand-written
offer-file fixture modelled on the AWS format; its prices are not real.

## Usage files

`examples/usage.yml` and `examples/usage-multi-region.yml` contain
illustrative usage figures (requests, GB stored, data processed). They are
invented for the demo and do not describe any real workload.
